# Assignments

Course-lab notebooks organised by day. Each day folder contains the student
notebook and a README with instructions. Click an **Open in Colab** badge to
launch a notebook directly — no local setup required.

Day 1 and Day 2 carry the **revised Nigeria versions** of the labs (Colab-verified 2026-08-02).
Days 3–5 currently carry the **pilot versions**, pending Nigeria revision.
